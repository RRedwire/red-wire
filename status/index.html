Checks run in your browser, from your network. That makes them honest — and useful — but it also means a failure can be a filter, a DNS problem or a CORS policy rather than downtime.

No synthetic uptime history. No server-side telemetry. Each row is a single anonymous fetch with mode: no-cors and a seven-second timeout. If you run Redline yourself, point a row at your own /health endpoint.
