How the wire moves

Boring on purpose.
Fast where it counts.

RedWire is built on the same open stack the rest of the scene uses — we just package it so you can run it without reverse-engineering a hundred forks.

  • Ultraviolet Rewrites HTML, CSS and JavaScript on the fly so the open web renders inside your origin.
  • BareMux One transport interface. Swap a relay, a bare server or an encrypted tunnel without touching the app.
  • Epoxy + WISP Encrypted streams over WebSocket. TLS terminates at the edge, not in the middle.

Ship your own edge

One command.
Your infrastructure.

Redline is a complete, self-contained deployment — shell, service worker, transport and relay. No accounts, no ads, no upstream dependency you can't replace.

  • Runs on any Node 20+ host with WebSocket support.
  • Dockerfile included — Fly, Railway, Render or a plain VPS.
  • Static site deploys to Cloudflare Pages; the relay stays a container.
