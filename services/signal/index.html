Signal

One link.
Every mirror.

A single manifest of access points, rendered as a page that always finds a way in. Edit links.json, deploy the folder, done. No build step, no database, no telemetry.

links.json 
{
  "name": "Signal",
  "updated": "2026-11-06",
  "links": [
    { "name": "Infrared", "url": "https://infrared.earth", "tag": "proxy", "status": "live", "note": "the flagship proxy" }
  ]
}

Each entry becomes a card. status accepts live, kit, wip or planned. Remove a mirror when it dies — there is nothing to rebuild.
