What happens
when you browse.

Redline keeps the stack small and inspectable. Every layer has one job and can be replaced.

  • ShellThe page registers a service worker at /service/.
  • RewriteUltraviolet fetches and rewrites HTML, CSS and JavaScript in your origin.
  • TransportBareMux hands the request to Epoxy, which opens an encrypted stream over WISP.
  • RelayThe Node relay opens the upstream TCP connection and pipes bytes back.
bash — deploy redline 
$ git clone https://github.com/RRedwire/red-wire
$ cd red-wire/services/redline
$ npm install
$ npm start

> redline listening on :8080
> wisp relay at /wisp/
# open http://localhost:8080

Hosting notes

HTTPS is required. Service workers only register on secure origins. Use HTTPS in production, or localhost for development.
The relay needs WebSockets. Cloudflare Pages can host the static shell but not the WISP relay. Run Redline on a container host with WebSocket support.
No upstream dependency. Redline serves every byte itself. The only external dependency is the site you choose to visit.
